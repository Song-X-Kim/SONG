## ① 한눈에 보기

> HashMap에서 **키 유무에 따라 다르게 동작**해야 할 때 쓰는 메서드들.

### 조회·삽입 기본

| 메서드 | 키 없을 때 | 키 있을 때 | Map 변경 |
|---|---|---|---|
| `putIfAbsent(k, v)` | value 넣음 | 그대로 | ✅ |
| `getOrDefault(k, def)` | default 리턴 | 값 리턴 | ❌ |

### compute 패밀리

| 메서드 | 키 없을 때 | 키 있을 때 |
|---|---|---|
| `compute(k, fn)` | `fn(k, null)` 호출 | `fn(k, oldV)` 호출 |
| `computeIfAbsent(k, fn)` | `fn(k)` 결과 넣음 | 그대로 |
| `computeIfPresent(k, fn)` | 아무것도 안 함 | `fn(k, oldV)` 갱신 |
| `merge(k, val, fn)` | val 그냥 넣음 | `fn(oldV, val)` 갱신 |

> 💡 **요약**  
> "키 없으면 기본값, 있으면 함수 동작" → `merge`  
> "키 없을 때만 초기화" → `computeIfAbsent`

## ② compute 패밀리 상세

### 시그니처

```java
// 항상 재계산
V compute(K key, BiFunction<K, V, V> fn);

// 없을 때만 초기화 (게으른 초기화)
V computeIfAbsent(K key, Function<K, V> fn);

// 있을 때만 갱신
V computeIfPresent(K key, BiFunction<K, V, V> fn);

// 없으면 기본값, 있으면 fn(old, val)
V merge(K key, V value, BiFunction<V, V, V> fn);
```

### null 처리 규칙 ⚠️

자주 까먹는 부분:

| 메서드 | fn이 null 반환할 때 |
|---|---|
| `compute` | **매핑 삭제** |
| `computeIfAbsent` | **매핑 추가 안 함** |
| `computeIfPresent` | **매핑 삭제** |
| `merge` | **매핑 삭제** |

### merge 동작 시각화

```java
Map<String, Integer> map = new HashMap<>();

// 1) 키 "apple" 없음 → value 1 그냥 넣음 (기본동작)
map.merge("apple", 1, Integer::sum);
// map = {apple=1}

// 2) 키 "apple" 있음 → fn(1, 1) = 2 로 갱신
map.merge("apple", 1, Integer::sum);
// map = {apple=2}

// 3) 또 호출 → fn(2, 1) = 3
map.merge("apple", 1, Integer::sum);
// map = {apple=3}
```

> ⚠️ **merge vs compute 헷갈리지 않기**
> - `compute`는 **함수 하나**로 모든 케이스 처리 (없으면 oldV가 null)
> - `merge`는 **없을 때 쓸 기본값(value)**을 인자로 받고, **있을 때만 함수** 호출

### 같은 동작 세 가지 방식

```java
// 단어 카운팅 세 방식

// merge — 간결 ⭐
map.merge(word, 1, Integer::sum);

// compute — null 체크 직접
map.compute(word, (k, v) -> v == null ? 1 : v + 1);

// getOrDefault + put — 옛날 스타일
map.put(word, map.getOrDefault(word, 0) + 1);
```

## ③ K·V 순회

### entrySet() — 같이 빼올 때

```java
// 방법 1: for-each + Map.Entry (제일 자주)
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    String k = entry.getKey();
    Integer v = entry.getValue();
}

// 방법 2: var로 짧게 (Java 10+)
for (var entry : map.entrySet()) {
    var k = entry.getKey();
    var v = entry.getValue();
}

// 방법 3: forEach 람다 (가장 간결) ⭐
map.forEach((k, v) -> {
    System.out.println(k + " = " + v);
});

// 방법 4: Stream으로 가공
map.entrySet().stream()
   .filter(e -> e.getValue() > 10)
   .map(Map.Entry::getKey)
   .forEach(System.out::println);
```

### 한쪽만 필요할 때

```java
// 키만
for (String k : map.keySet()) { ... }

// 값만
for (Integer v : map.values()) { ... }

// 값들의 합
int sum = map.values().stream()
             .mapToInt(Integer::intValue)
             .sum();
```

### ⚠️ 순회 중 삭제 주의

순회 중에 `map.remove(k)` 직접 호출하면 `ConcurrentModificationException`.

```java
// ❌ 안 됨
for (var e : map.entrySet()) {
    if (e.getValue() == 0) map.remove(e.getKey());
}

// ✅ 안전한 조건부 삭제
map.entrySet().removeIf(e -> e.getValue() == 0);
```

## ④ 람다 함정

### 오늘 잡힌 버그

```java
map.computeIfPresent(c, (k, v) -> {v - 1});  // ❌ 컴파일 에러
```

중괄호 안에 `return`이 없고, `v - 1` 자체도 단독 statement로 안 됨.

### 왜 에러인가?

1. **블록 람다 규칙**  
   람다에 `{}`를 쓰면 *block lambda* → 값 반환하려면 `return` 필수

2. **statement 제약**  
   Java에서 statement로 쓸 수 있는 표현식은 제한적:  
   메서드 호출, 대입, 증감, `new`. 산술식 `v - 1`은 statement로 불가

3. **반환 타입**  
   `computeIfPresent`의 `BiFunction<K, V, V>`는 V를 반환해야 하는데 `return` 자체가 없음

### ✅ 고치는 방법

```java
// 방법 1: 중괄호 빼서 표현식 람다 (권장)
map.computeIfPresent(c, (k, v) -> v - 1);

// 방법 2: 중괄호 + return
map.computeIfPresent(c, (k, v) -> { return v - 1; });
```

### 표현식 람다 vs 블록 람다

```java
// 표현식 람다 — 결과가 자동으로 반환
Function<Integer, Integer> a = x -> x * 2;

// 블록 람다 — return 명시
Function<Integer, Integer> b = x -> { return x * 2; };

// 여러 줄 처리할 땐 블록 람다 필요
Function<Integer, Integer> c = x -> {
    int y = x + 1;
    int z = y * 2;
    return z;
};

// void 람다는 return 없어도 됨
Runnable r = () -> { System.out.println("hi"); };
```

> 💡 **기억법**  
> 화살표 뒤에 **표현식 하나**면 중괄호 X (자동 반환)  
> **여러 줄이나 명시적 흐름**이면 중괄호 + return

📖 [Lambda Body — JLS §15.27.2 (Java SE 21)](https://docs.oracle.com/javase/specs/jls/se21/html/jls-15.html#jls-15.27.2)

## ⑤ 치트시트

코테에서 바로 쓰는 패턴.

### ① 단어/문자 카운팅

```java
Map<String, Integer> count = new HashMap<>();
for (String w : words) {
    count.merge(w, 1, Integer::sum);
}
```

### ② Map\<K, List\<V\>\> 그룹핑

```java
Map<String, List<Integer>> group = new HashMap<>();
group.computeIfAbsent(key, k -> new ArrayList<>()).add(value);
```

### ③ 조건부 증가/감소

```java
// 키가 있을 때만 -1
map.computeIfPresent(c, (k, v) -> v - 1);

// 0이 되면 매핑 자체를 삭제
map.computeIfPresent(c, (k, v) -> v - 1 == 0 ? null : v - 1);
```

### ④ 안전한 기본값 조회

```java
int cnt = map.getOrDefault(key, 0);
```

### ⑤ 없을 때만 초기 세팅

```java
map.putIfAbsent(key, defaultValue);
```

### ⑥ 키·값 한 번에 순회

```java
map.forEach((k, v) -> System.out.println(k + "=" + v));
```

### ❌ 하지 말 것

```java
// 1) 람다에 중괄호 쓰고 return 빼먹기
map.computeIfPresent(c, (k, v) -> {v - 1});  // 컴파일 에러

// 2) 순회 중 map.remove 직접 호출
for (var e : map.entrySet()) {
    if (e.getValue() == 0) {
        map.remove(e.getKey());  // ConcurrentModificationException
    }
}

// 3) Stack 새로 만들기 (대신 ArrayDeque 써야 함)
Stack<Integer> s = new Stack<>();  // legacy, synchronized 오버헤드
```

> ✅ **다시 정리** — 키 없을 때 처리 4가지  
> `putIfAbsent` (넣기) · `getOrDefault` (조회) · `computeIfAbsent` (계산해서 넣기) · `merge` (있으면 fn, 없으면 기본값)
