## 한눈에 보기

| 메서드 | 어디 소속 | 시간복잡도 | 핵심 포인트 |
|---|---|---|---|
| `Math.max(a, b)` | `java.lang.Math` | O(1) | **인자 2개만**, 가변인자 ❌ |
| `s.toCharArray()` | `java.lang.String` | O(n) | 새 배열 **복사** 반환 |
| `s.charAt(i)` | `java.lang.String` | O(1) | 추가 메모리 없음 |
| `s.split(regex)` | `java.lang.String` | O(n) | 정규식, 루프 밖에서 1회 호출 |
| `s.replace(c, r)` | `java.lang.String` | O(n) | 단순 치환, 빠름 |
| `s.replaceAll(regex, r)` | `java.lang.String` | O(n) | 정규식 기반, 오버헤드 있음 |
| `Integer.parseInt(s)` | `java.lang.Integer` | O(n) | `NumberFormatException` 주의 |

> **한 줄 요약** — String은 immutable, char는 본질적으로 int, O(n) 메서드는 루프 밖으로.

## 1. Math.max / Math.min

### 시그니처

```java
public static int max(int a, int b)
public static long max(long a, long b)
public static float max(float a, float b)
public static double max(double a, double b)
```

### 핵심 규칙

- **인자 2개 전용** (JS의 `Math.max(...arr)`처럼 가변인자 ❌)
- 4가지 원시 타입에 대해 오버로드
- `Math.min`도 시그니처 동일

### 3개 이상 비교

```java
// 중첩
Math.max(a, Math.max(b, c));

// 스트림
IntStream.of(a, b, c).max().getAsInt();
```

### 배열/리스트 최댓값

```java
// for문 (코테 추천 — 가장 빠름)
int max = Integer.MIN_VALUE;
for (int n : arr) max = Math.max(max, n);

// 스트림
int max = Arrays.stream(arr).max().getAsInt();
int max = Collections.max(list);
```

## 2. String은 immutable

### 핵심 규칙

> String은 한 번 만들면 **절대 변하지 않음**.
> 모든 변형 메서드는 **새 String을 반환**한다.

```java
String s = "hello world";

s.replace(" ", "");       // ❌ 반환값 버림 → s는 그대로
s = s.replace(" ", "");   // ✅ 재할당해야 적용됨
```

### 변형 메서드 목록 (전부 새 String 반환)

```java
s.toLowerCase();
s.toUpperCase();
s.trim();
s.strip();
s.replace(target, replacement);
s.replaceAll(regex, replacement);
s.replaceFirst(regex, replacement);
s.substring(start, end);
s.concat(other);
```

### replace vs replaceAll

| 메서드 | 첫 인자 | 정규식 사용 | 속도 |
|---|---|:---:|:---:|
| `replace(CharSequence, CharSequence)` | 일반 문자열 | ❌ | **빠름** |
| `replaceAll(String, String)` | **정규식** | ✅ | 보통 |

```java
// ✅ 단순 치환은 replace
s.replace(" ", "");

// regex 필요할 때만 replaceAll
s.replaceAll("\\s+", "");  // 공백/탭/개행 전부
```

## 3. char 연산 규칙

### char는 본질적으로 int

```java
char a = 'A';   // 실제로는 65
char b = 'B';   // 실제로는 66

a + b           // 131  ← int 산술!
(char)(a + 1)   // 'B'  ← 캐스팅하면 char
```

### char + String 연산

```java
char min = '1', max = '4';

min + max         // 101  (int!)
min + " " + max   // "1 4"  ← String이 끼면 문자열 연결
"" + min + max    // "14"  ← 맨 앞에 빈 문자열로 강제
```

### StringBuilder 안전 사용

```java
// ⚠️ 헷갈리기 쉬움 (이건 우연히 동작)
sb.append(min + " " + max);

// ✅ 의도 명확, 항상 안전
sb.append(min).append(" ").append(max);
```

## 4. toCharArray vs charAt

### 동작 차이

```java
// toCharArray: 새 char[] 복사 반환 (immutable 보호)
char[] arr = s.toCharArray();   // O(n) — 메모리 새로 할당
arr[0] = 'X';                   // 원본 s는 영향 없음

// charAt: 내부 데이터 인덱스 접근
char c = s.charAt(0);            // O(1) — 추가 메모리 없음
```

### JDK 9+ Compact Strings

- String 내부는 `char[]`가 아니라 **`byte[]` + coder 플래그**
- LATIN1이면 1바이트, UTF-16이면 2바이트
- `toCharArray()` 호출 시 byte → char **변환** + 새 배열 생성

### 선택 기준

| 상황 | 추천 |
|---|---|
| 인덱스 없이 순회 | `for (char c : s.toCharArray())` |
| 인덱스 필요 | `s.charAt(i)` |
| 메모리 민감 (큰 문자열) | **`charAt(i)`** |
| 한 번 만들어 여러 번 접근 | `toCharArray()` |

## 5. split 동작과 비용

### 시그니처

```java
public String[] split(String regex)
```

- 첫 인자는 **정규식**
- 결과는 `String[]` 배열
- 시간복잡도 O(n), 공간 O(n)

### 루프 밖에서 한 번만 호출

```java
// ✅ 정상 — O(n)
String[] tokens = s.split(" ");
for (String t : tokens) { ... }

// ❌ 루프 안 호출 — O(n²)
for (int i = 0; i < k; i++) {
    String[] tokens = s.split(" ");
}
```

### split vs StringTokenizer

| 방법 | 정규식 | 속도 | 가독성 |
|---|:---:|:---:|:---:|
| `split` | ✅ | 보통 | 👍 |
| `StringTokenizer` | ❌ | **빠름** | 보통 |

```java
StringTokenizer st = new StringTokenizer(s, " ");
while (st.hasMoreTokens()) {
    int n = Integer.parseInt(st.nextToken());
}
```

- 일반 코테: `split` (가독성)
- 입력 큰 백준식: `BufferedReader` + `StringTokenizer` 정석

## 6. 최댓값과 최솟값 디버깅 — 학습 포인트

### 처음 잘못 잡은 풀이

```java
char max = s.charAt(0);
char min = s.charAt(0);
for (char c : s.toCharArray()) {
    if (c - max >= 0) max = c;
    if (c - min <= 0) min = c;
}
return min + " " + max;
```

### 왜 실패했나

입력 `"1 2 3 4"`는 **숫자 4개를 공백 구분**한 것 → **문자 7개가 아님**.

| 문자 | `'1'` | `' '` | `'2'` | `' '` | `'3'` | `' '` | `'4'` |
|---|---|---|---|---|---|---|---|
| 아스키 | 49 | **32** | 50 | 32 | 51 | 32 | 52 |

- 공백(32)이 숫자 문자(48~57)보다 작음 → **최솟값 = 공백**
- 음수 `"-4"`는 **두 글자** → char 하나로 표현 불가
- 공백 제거(`s = s.replace(" ", "")`)해도 `'-'`가 또 끼어서 동일한 함정

### 정답 풀이

```java
class Solution {
    public String solution(String s) {
        int min = Integer.MAX_VALUE;
        int max = Integer.MIN_VALUE;

        for (String token : s.split(" ")) {
            int n = Integer.parseInt(token);
            min = Math.min(min, n);
            max = Math.max(max, n);
        }

        return min + " " + max;
    }
}
```

### 교훈

> **숫자 비교는 숫자로**. char 단위 비교는 단일 자릿수 양수에서만 우연히 통한다.

## 7. 코테에서 바로 쓰는 패턴

### 패턴 1: 공백 구분 숫자 입력 파싱

```java
int[] nums = Arrays.stream(s.split(" "))
                   .mapToInt(Integer::parseInt)
                   .toArray();
```

### 패턴 2: 문자열에서 알파벳/숫자만 추출

```java
for (int i = 0; i < s.length(); i++) {
    char c = s.charAt(i);
    if (Character.isDigit(c)) { ... }
    if (Character.isLetter(c)) { ... }
}
```

### 패턴 3: 동시에 min/max 갱신

```java
int min = Integer.MAX_VALUE;
int max = Integer.MIN_VALUE;
for (int n : arr) {
    min = Math.min(min, n);
    max = Math.max(max, n);
}
// 정렬보다 빠름 — O(n) vs O(n log n)
```

### 패턴 4: char를 숫자로 변환

```java
char c = '7';
int n = c - '0';        // 7  ← 아스키 차이 활용
int n = Character.getNumericValue(c);  // 7  ← 안전한 방법
```

## ❌ 하지 말 것

```java
// 1) Math.max에 3개 이상 인자
Math.max(a, b, c);                    // 컴파일 에러

// 2) String 변형 메서드 반환값 무시
s.replace(" ", "");                   // s는 안 바뀜
s.replaceAll(" ", "");                // 동일

// 3) char + char를 문자열로 기대
sb.append(c1 + c2);                   // 숫자 덧셈됨!

// 4) char 단위로 숫자 문자열 비교
for (char c : s.toCharArray()) {      // 공백, 음수 처리 불가
    if (c - min <= 0) min = c;
}

// 5) for문 안에서 O(n) 호출
for (int i = 0; i < n; i++) {
    char c = s.toCharArray()[i];       // O(n²)!
}

// 6) for문 안에서 split 반복
for (int i = 0; i < k; i++) {
    String[] tokens = s.split(" ");    // 매번 O(n)
}

// 7) 대소문자 오타 (Java는 camelCase 표준)
new Stringbuilder();                   // ❌ → StringBuilder
s.tocharArray();                       // ❌ → toCharArray
```
