## 한눈에 보기

| 개념 | 정의 | 핵심 | 복잡도 |
|---|---|---|---|
| gcd (최대공약수) | 둘 다 나누는 가장 큰 수 | 유클리드 호제법 | `O(log min(a,b))` |
| lcm (최소공배수) | 공통 배수 중 가장 작은 수 | `a / gcd * b` | gcd와 동일 |
| N개 lcm | 배열 전체의 lcm | `answer = lcm(answer, x)` 누적 | `O(n · log M)` |

**한 줄 요약:** gcd는 "나머지로 줄이기", lcm은 "곱 ÷ gcd", N개는 "두 개씩 접기(fold)".

## 1. gcd 와 lcm 이란

영어 약자라 낯설 뿐, 학교에서 배운 **최대공약수 / 최소공배수** 그대로다.

- **gcd(12, 8) = 4** : 12와 8을 둘 다 나누는 가장 큰 수
- **lcm(12, 8) = 24** : 12의 배수와 8의 배수 중 공통으로 가장 작은 수

핵심 공식:

```
lcm(a, b) = a × b ÷ gcd(a, b)
lcm(12,8) = 96 ÷ 4 = 24
```

`a × b`는 공통 배수긴 하지만 겹치는 부분(gcd)을 두 번 센 값이라 너무 크다. 그 gcd만큼 나눠주면 최소가 된다. 코드에선 `a / gcd * b`로 써서 **나누기를 먼저** 해 오버플로 여유를 둔다.

## 2. 유클리드 호제법

gcd를 빠르게 구하는 방법. 딱 하나의 사실을 반복한다:

```
gcd(a, b) = gcd(b, a % b)
```

큰 수를 나머지로 계속 줄이고, **나머지가 0이 되는 순간** 남은 수가 gcd다.

```java
private int gcd(int a, int b) {
    while (b != 0) {   // 나머지(=남은 칸)가 0 될 때까지
        int t = b;     // 옛 b를 잠깐 보관
        b = a % b;     // 새 b = a를 b로 나눈 나머지
        a = t;         // 새 a = 옛 b
    }
    return a;          // 남은 a가 gcd
}
```

| 코드 | 동작 | 그림 대응 |
|---|---|---|
| `while (b != 0)` | b≠0이면 반복 | 남은 칸이 있으면 계속 |
| `int t = b;` | 옛 b(세로) 보관 | 정사각형 한 변 기억 |
| `b = a % b;` | 나머지 계산 | 정사각형 떼고 **남은 칸** |
| `a = t;` | 옛 b를 a로 | 남은 칸이 다음 직사각형 |
| `return a;` | 남은 a 반환 | 마지막 정사각형 = gcd |

> `t`가 필요한 이유: `(a, b)`를 `(b, a%b)`로 바꾸려는데, `b`를 먼저 덮어쓰면 옛 `b`가 사라지므로 백업한다.

추적 예시 `gcd(12, 8)`:

```text
a=12, b=8
 12 % 8 = 4  →  (a=8,  b=4)
  8 % 4 = 0  →  (a=4,  b=0)
 b==0 → return 4
```

인자 순서는 신경 쓸 필요 없다. `gcd(8, 12)`도 첫 바퀴 `8 % 12 = 8`로 자동으로 `(12, 8)`이 된다.

## 3. 왜 이 식이 성립할까

근거는 **사실 하나**: "어떤 수 `d`로 나누어떨어지는 두 수를 더하거나 빼면, 결과도 `d`로 나누어떨어진다."

```
12 = 2×6,  8 = 2×4
12 − 8 = 2×6 − 2×4 = 2×(6−4) = 2×2   → 4도 2의 배수
```

나눗셈은 `a = (몫)×b + 나머지`로 쓸 수 있으므로 `나머지 = a − (몫)×b`.

- `d`가 a, b를 둘 다 나누면 → `(몫)×b`도 배수 → **나머지도 d의 배수**
- `d`가 b, 나머지를 둘 다 나누면 → `a = (몫)×b + 나머지`도 배수

즉 **(a, b)의 공약수 집합 = (b, 나머지)의 공약수 집합** → 가장 큰 값(gcd)도 같다.

```text
12와 8의 공약수 = {1, 2, 4}
 8과 4의 공약수 = {1, 2, 4}   ← 동일 → gcd 동일
```

끝나는 이유: `(g, 0)`에 도달하면 0은 아무 수로나 나눠지므로 공약수는 g의 약수들뿐 → 가장 큰 건 g. 그래서 `gcd(g, 0) = g`.

> `d`는 문제 속 숫자가 아니라 "공약수 아무거나 하나"를 부르는 이름. 한 글자로 모든 공약수를 한 번에 다룬다.

## 4. 그림으로 보는 직관

**gcd = 가로 a, 세로 b 직사각형을 빈틈없이 채우는 가장 큰 정사각형의 한 변.**

`gcd(12, 8)`:

```text
1단계 — 가로 12, 세로 8
  ┌────────┬───┐
  │  8×8   │ 4 │   8 정사각형 1개 떼면 4×8 남음
  └────────┴───┘   12 = 1×8 + 4   (12 % 8 = 4)

2단계 — 가로 8, 세로 4   (남은 4×8이 다음 직사각형)
  ┌────┬────┐
  │4×4 │4×4 │      4 정사각형 2개로 딱!
  └────┴────┘      8 = 2×4 + 0    (8 % 4 = 0)

→ 마지막 정사각형 4 = gcd(12, 8)
```

- `a % b` = 정사각형 떼고 **남은 칸** (= 다음 직사각형의 세로)
- `b == 0` = 남는 칸 없음 = 끝
- 서로소면 1×1 정사각형까지 쪼개짐 → gcd = 1

> 인터랙티브 버전은 `gcd-code-visual.jsx` 참고 (코드 줄 ↔ 도형 동기화).

## 5. 최종 제출 코드

```java
class Solution {
    public int solution(int[] arr) {
        int answer = 1;
        for (int x : arr) {
            answer = lcm(answer, x);   // 두 개씩 누적(fold)
        }
        return answer;
    }

    private int gcd(int a, int b) {    // 유클리드 호제법
        while (b != 0) {
            int t = b;
            b = a % b;
            a = t;
        }
        return a;
    }

    private int lcm(int a, int b) {
        return a / gcd(a, b) * b;       // 곱하기 전에 나눠서 오버플로 여유
    }
}
```

흐름: **gcd(나머지로 줄이기) → lcm(곱 ÷ gcd) → answer에 하나씩 접기.**
`answer = 1`로 시작하는 이유: `lcm(1, x) = x`라 첫 원소가 그대로 들어오는 안전한 출발점.

## 6. 디버깅 틀린 풀이 분석

### 시도 1 — sqrt 범위 + "모두 나눠질 때만" 나누기
```java
while (n <= Math.sqrt(arr[arr.length - 1])) { ... }
```
- ❌ √보다 큰 소인수를 통째로 놓침
- ❌ "전부 나눠질 때만"은 GCD식 발상 → LCM이 아님
- 결과: 거의 전부 실패

### 시도 2 — n을 큰 수부터 ↓, 그래도 "모두 나눠질 때만"
- 2개일 땐 통과(우연): `gcd × (a/g) × (b/g) = a·b/g = lcm(a,b)`
- 3개 이상에서 깨짐: 전체 공통 GCD 하나만 빼면, **두 수끼리만 겹치는 인수가 곱에서 중복 카운트**됨

**반례 `[4, 6, 8]`** (정답 24)
```text
4=2², 6=2·3, 8=2³ → lcm = 2³·3 = 24
시도2: 공통 2로 한 번 나눔 → [2,3,4], answer=2
       곱 = 2 × 2 × 3 × 4 = 48   ❌ ([2,3,4]의 2와 4가 또 겹침)
```

**교훈:** N개 LCM은 "공통 인수 한 번 빼기"가 아니라 **두 개씩 lcm 누적(fold)** 이 정답이다.

## 7. 바로 쓰는 코테 패턴

```java
// gcd / lcm 한 쌍 — 그대로 복붙
int gcd(int a, int b) { while (b != 0) { int t = b; b = a % b; a = t; } return a; }
int lcm(int a, int b) { return a / gcd(a, b) * b; }

// 배열 전체 lcm
int ans = 1;
for (int x : arr) ans = lcm(ans, x);

// 배열 전체 gcd
int g = arr[0];
for (int x : arr) g = gcd(g, x);
```

- 오버플로: `a / gcd * b` 순서로 (곱 먼저 하면 커진다). 값이 매우 크면 `long` 또는 `BigInteger` 사용
- `BigInteger`엔 `gcd`가 내장 → `a.gcd(b)`

## 8. 이렇게 하지 말 것

- ❌ "원소가 **모두** 나눠질 때만" 나누기 — 이건 LCM이 아니다 (공통 GCD만 빼는 꼴)
- ❌ `while (n <= Math.sqrt(max))` — √보다 큰 소인수 누락
- ❌ "공통 GCD × 나눈 것들의 곱" — 2개에서만 LCM, 3개↑ 중복 카운트로 깨짐
- ❌ `arr = next;` 후 두 배열이 같은 객체 — 별칭(aliasing) 버그
- ❌ `int next = new int[arr.length];` — 컴파일 에러 (`int[] next` 여야 함)
